1. **Никакого плоского аниме-арта (No flat cel-shading):** Все мистические образы (Бернкастель, Эрика, Дланор, Уиллард, Клер) подаются исключительно через теневые силуэты, гравировку на тёмном металле, рентген-эффекты, глитч-голограммы или контурные неоновые контуры поверх реальных фотореалистичных государственных символов США.
2. **Трёхслойная композиция (Depth Hierarchy):**
   - **Слой 1 (Фон):** Государственные реликвии и архитектура США (Капитолий, Белый дом, Минюст, сервера АНБ, радарные сетки NORAD), затянутые в цифровой шум и шахматную сетку.

   - **Слой 3 (Передний план):** Осколки стекла, армированный синий/серебряный скотч (Duct Tape), лазерные клинки Истины, пурпурные кристаллы или трещины визора.

## 4. ИНСТРУКЦИЯ ПО АВТОМАТИЧЕСКОЙ ПОСТОБРАБОТКЕ

В сабмод добавлены два полнофункциональных инструмента:
1. **Python-скрипт (`tools/tfr_icon_filter.py`)**:
   ```bash
   pip install pillow
   python tools/tfr_icon_filter.py
   ```
2. **PowerShell/.NET-скрипт (`tools/tfr_icon_filter.ps1`)** (работает автономно на любой Windows машине без установки Python):
   ```powershell
   powershell -ExecutionPolicy Bypass -File tools/tfr_icon_filter.ps1
   ```

Оба скрипта:
- Автоматически кадрируют и подгоняют изображение под стандартный размер `92x92` пикселей.
- Отрисовывают металлическую подложку-шеврон TFR с пурпурной/циановой окантовкой и заклепками.
